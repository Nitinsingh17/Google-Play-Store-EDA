Google Play Store Apps - Exploratory Data Analysis (EDA)

Project Overview

This project explores the Google Play Store Apps dataset using Python to understand app-related information, including ratings, reviews, categories, installations, and pricing.

The objective is to apply data cleaning and exploratory data analysis techniques to examine the dataset and better understand the characteristics of mobile applications.

Dataset Information

Dataset: Google Play Store Apps

Source: "Kaggle - Google Play Store Apps" (https://www.kaggle.com/datasets/lava18/google-play-store-apps)

Original Dataset: 10,841 records and 13 columns

The dataset includes information about app names, categories, ratings, reviews, size, installs, type, price, content ratings, genres, and application versions.

Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Kaggle

Project Workflow

Data Understanding

Loaded the dataset using Pandas and inspected its structure, column names, data types, and sample records.

Data Cleaning

Examined missing values and applied data-cleaning techniques, including mean imputation for missing app ratings.

Exploratory Data Analysis

Worked with Google Play Store app data to examine its characteristics and explore relationships between application attributes.

Project Notebook

"View the Python Jupyter Notebook" (app-insights-analysis.ipynb)

How to Run

Open the notebook in Kaggle or Jupyter Notebook.

Download or attach the Google Play Store Apps dataset from Kaggle and ensure the CSV file path matches the path used in the notebook.

Install the required Python libraries if running locally.

Project Purpose

This project was developed as a hands-on Python data analysis exercise to strengthen skills in dataset exploration, data cleaning, and exploratory data analysis.
