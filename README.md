## Project Overview

Exploratory Data Analysis of Google Play Store applications using Python to examine app ratings, reviews, installs, categories, and pricing. The project focuses on data cleaning, identifying patterns, and understanding app-related trends.

## Dataset

- **Source:** [Google Play Store Apps - Kaggle](https://www.kaggle.com/datasets/lava18/google-play-store-apps)
- **Size:** 10,841 records and 13 columns in the original dataset
- **Key Features:** Category, Rating, Reviews, Installs, Type, Price, and Content Rating

## Requirements & Technologies

- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook
- **Techniques:** Data Cleaning, Data Manipulation, Exploratory Data Analysis

## Project Workflow

1. Loaded and explored the dataset to understand its structure.
2. Examined missing values and data types.
3. Handled missing ratings using mean imputation.
4. Explored app attributes and their relationships.

## Challenges Faced

- Handling missing app ratings.
- Identifying data-quality issues that could affect analysis.
- Preparing the dataset for meaningful comparisons.

## Insights & Recommendations

The analysis examines app ratings, categories, reviews, and installations to understand application characteristics.

**Recommendations for Further Analysis:**

- Compare app performance across different categories.
- Investigate relationships between reviews, ratings, and installations.
- Explore differences between free and paid applications.
